# Weather App

Aplicación web para consultar el clima actual de cualquier ciudad, construida con React, TypeScript y Vite. Usa la API gratuita de [Open-Meteo](https://open-meteo.com/) para geocodificar la ciudad y obtener el pronóstico.

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Scripts

- `pnpm dev` — inicia el servidor de desarrollo
- `pnpm build` — compila TypeScript y genera el build de producción
- `pnpm lint` — corre ESLint
- `pnpm preview` — sirve el build de producción localmente
